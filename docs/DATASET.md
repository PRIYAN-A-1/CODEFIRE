# Dataset operation and provenance

Sources are explicitly approved local directories with allowlisted SPDX identifiers. This is a permission gate, not legal verification: maintain actual license text, commit revision, attribution and access/removal records yourself. `source_url` and `commit_sha` are optional provenance fields; fill them for real corpora. Original fixture files are CC0-1.0 under examples/LICENSE. No GitHub crawl or third-party dataset was downloaded.

Collection excludes dependency/build folders, symlinks, unsupported types, binary/NUL, empty, oversized/minified, generated-looking, secret-looking and email-containing records. Python gets AST validation; other languages receive only heuristic checks. Exact content hashes and global token-set Jaccard prevent accepted duplicates across splits; retained first source wins deterministically. The Jaccard detector is conservative, quadratic, and may reject semantically different programs with similar token sets. It is not a scalable MinHash implementation. Keep known benchmark hashes in `benchmark_sha256`; fuzzy benchmark contamination and comprehensive credential/PII detection are not guaranteed.

Default repository hashes map 80/10/10 to train/validation/test. Explicit source split overrides are useful for curated held-out repositories, but never put the same repository in multiple splits. Hash splits can be empty for a small corpus; training fails clearly if validation has no complete sequences. Global dedup precedes writes, preventing retained duplicates from crossing splits. For large corpora use an independently audited split and near-duplicate pipeline.

The tokenizer trains only accepted code using ByteLevel BPE with the entire byte alphabet; no Unicode normalizer or whitespace collapse. It appends neither BOS nor EOS automatically. Preparation appends an EOS per code record, packs bounded token shards per split and records hashes. Training reads memory maps, samples full nonoverlapping windows with replacement, and does not straddle shard boundaries. Final short tails are omitted from training windows. Windows can cross EOS-separated file boundaries within a shard.

Collect currently accumulates accepted records and token sets in RAM. Token preparation streams record lines and bounded buffers; training uses memmap, but startup hash verification reads each shard into RAM. Keep shards moderate. Preparation reuses verified matching complete manifests; interruption rebuilds incomplete shards. SQLite ingest offsets, removal propagation, license-text export, remote object-store streaming and incremental collection at massive scale are outstanding.
